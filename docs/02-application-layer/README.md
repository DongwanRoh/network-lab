# 📚 02. 응용 계층 프로토콜 (Application Layer)

## 📌 다룰 프로토콜 & 주제
1. **HTTP (Hypertext Transfer Protocol)**
   - HTTP/1.1: Persistent Connections, Head-of-Line Blocking, Cookie & Session
   - HTTP/2: Binary Framing, Multiplexing, Stream Prioritization, Server Push
   - HTTP/3: QUIC (Quick UDP Internet Connections) 기반 동작, 0-RTT
2. **HTTPS & TLS / SSL**
   - 대칭키 vs 공개키(비대칭키) 암호화
   - TLS Handshake 과정 (인증서 검증, 세션 키 생성)
3. **WebSocket & SSE (Server-Sent Events)**
   - HTTP Upgrade 핸드셰이크
   - 전이중(Full-Duplex) 실시간 양방향 통신
4. **DNS (Domain Name System)**
   - Root / TLD / Authoritative Name Server 계층 구조
   - 재귀적(Recursive) vs 반복적(Iterative) 질의
   - DNS Record Types: A, AAAA, CNAME, MX, TXT, NS
