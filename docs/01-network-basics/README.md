# 📚 01. 네트워크 기초 (Network Basics)

## 📌 다룰 내용
- **네트워크란 무엇인가?**: 호스트, 링크, 라우터, 패킷 교환(Packet Switching) vs 회선 교환(Circuit Switching)
- **네트워크 계층 모델 비교**:
  - OSI 7계층 (물리, 데이터링크, 네트워크, 전송, 세션, 표현, 응용)
  - TCP/IP 4계층 (Network Access, Internet, Transport, Application)
- **캡슐화(Encapsulation)와 역캡슐화(Decapsulation)**:
  - Header 추가 및 분리 과정
  - PDU(Protocol Data Unit): Frame, Packet/Datagram, Segment, Data/Message
- **주요 지표**: 대역폭(Bandwidth), 처리량(Throughput), 지연 시간(Latency/RTT), 패킷 손실(Packet Loss)
